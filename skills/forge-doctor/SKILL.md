# Forge Doctor

Use ContextForge to diagnose installation or repository-state issues.

## Instructions

1. Call `forge_doctor`.
2. Present the result as a clear markdown checklist or issue summary.
3. Put failures or warnings first.
4. If there are no issues, say that ContextForge looks healthy.

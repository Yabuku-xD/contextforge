# Forge Memory Timeline

Use ContextForge to inspect temporal history instead of a flat fact list.

## Instructions

1. Use the text after the command as the entity. If omitted, show the broad memory timeline.
2. Call `forge_memory_timeline`.
3. Summarize the major changes over time in chronological order.

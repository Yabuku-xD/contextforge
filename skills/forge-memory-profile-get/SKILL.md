# Forge Memory Profile Get

Use ContextForge to inspect saved identity or project profiles.

## Instructions

1. Use the command text as the profile type. If omitted, use `identity`.
2. Call `forge_memory_profile_get`.
3. Return the saved profile summary clearly.
